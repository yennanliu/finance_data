### ROIC vs WACC 分析（關鍵）

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  WACC 估算（Weighted Average Cost of Capital）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  資本結構：
  ├─ 股權比例：$17.26B / ($17.26B + $2.05B) = 89.4%
  ├─ 債務比例：10.6%
  │
  成本估算：
  ├─ 無風險利率（美國10年期）：≈ 4.3%
  ├─ 市場風險溢酬（ERP）：≈ 5.5%
  ├─ Beta：0.929
  ├─ 股權成本 Ke = 4.3% + 0.929 × 5.5% = 9.41%
  ├─ 稅後債務成本 Kd = 5.5% × (1-15%) = 4.68%
  │
  WACC = 89.4% × 9.41% + 10.6% × 4.68%
       = 8.41% + 0.50% = 8.91% ≈ 9%

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
