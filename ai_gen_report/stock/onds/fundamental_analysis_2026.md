## 12. 公平價值估算

### 12.1 估值方法論

#### 方法一：P/S 倍數法（基於 2026 指引）

```
假設: 2026 收入 = $110M, P/S = 6x（同業中位數）
估算市值 = $110M × 6 = $660M
估算股價 = $660M / 260M股 = $25.38/股

相較現價 $9.69 有 +162% 上漲空間
```

#### 方法二：收入情境 DCF（簡化）

```
假設:
• 2025E: $36M   → 2026E: $110M  → 2027E: $200M → 2028E: $280M → 2029E: $350M
• 終端成長率: 5%
• 折現率 (WACC): 18%（高風險公司）
• 終端 EV/EBITDA: 15x

DCF估算股價範圍: $12 - $28

考慮稀釋因子（潛在335M股）:
調整後 DCF 目標: $9.30 - $21.70
```

#### 方法三：同業收購溢價法

```
A類無人機公司被收購 P/S 倍數（歷史）:
• Shield AI（估值）: ~12x P/S
• Joby Aviation 上市: ~15x P/S（但載人）
• 小型防衛科技被收購: ~8-12x P/S

若 ONDS 以 2025 $36M × 10x 倍數：$360M/260M = $1.38（低估）
若 ONDS 以 2026 $110M × 10x 倍數：$1,100M/260M = $4.23（偏低）

顯示當前市值 $43.7B 已對未來有較高溢價定價
```
