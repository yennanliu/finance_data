## 2. 公司概覽與商業模式

Oracle Corporation (ORCL) 是一家全球領先的企業軟體公司，提供廣泛的產品和服務，用於建構、運行和支援全球企業資訊科技框架。其核心業務已從傳統的資料庫軟體和本地部署解決方案，成功轉型為以雲端服務為主的模式。Oracle的雲端軟體即服務 (SaaS) 產品涵蓋多個關鍵企業應用，包括Oracle Fusion Cloud企業資源規劃 (ERP)、Oracle Fusion Cloud企業績效管理 (EPM)、Oracle Fusion Cloud供應鏈與製造管理 (SCM)、Oracle Fusion Cloud人力資本管理 (HCM) 以及NetSuite應用套件。此外，Oracle Cloud Infrastructure (OCI) 作為其基礎設施即服務 (IaaS) 產品，正快速成長，與Amazon AWS、Microsoft Azure等巨頭競爭。截至報告日期，Oracle的市值為4040.4億美元，TTM年營收達673.6億美元。

## 2. 公司概覽與商業模式

Oracle Corporation (ORCL) 是一家全球領先的企業軟體公司，提供廣泛的產品和服務，用於建構、運行和支援全球企業資訊科技框架。其核心業務已從傳統的資料庫軟體和本地部署解決方案，成功轉型為以雲端服務為主的模式。Oracle的雲端軟體即服務 (SaaS) 產品涵蓋多個關鍵企業應用，包括Oracle Fusion Cloud企業資源規劃 (ERP)、Oracle Fusion Cloud企業績效管理 (EPM)、Oracle Fusion Cloud供應鏈與製造管理 (SCM)、Oracle Fusion Cloud人力資本管理 (HCM) 以及NetSuite應用套件。此外，Oracle Cloud Infrastructure (OCI) 作為其基礎設施即服務 (IaaS) 產品，正快速成長，與Amazon AWS、Microsoft Azure等巨頭競爭。截至報告日期，Oracle的市值為4040.4億美元，TTM年營收達673.6億美元。

## 2. 公司概覽與商業模式

Oracle Corporation (ORCL) 是一家全球領先的企業軟體公司，提供廣泛的產品和服務，用於建構、運行和支援全球企業資訊科技框架。其核心業務已從傳統的資料庫軟體和本地部署解決方案，成功轉型為以雲端服務為主的模式。Oracle的雲端軟體即服務 (SaaS) 產品涵蓋多個關鍵企業應用，包括Oracle Fusion Cloud企業資源規劃 (ERP)、Oracle Fusion Cloud企業績效管理 (EPM)、Oracle Fusion Cloud供應鏈與製造管理 (SCM)、Oracle Fusion Cloud人力資本管理 (HCM) 以及NetSuite應用套件。此外，Oracle Cloud Infrastructure (OCI) 作為其基礎設施即服務 (IaaS) 產品，正快速成長，與Amazon AWS、Microsoft Azure等巨頭競爭。截至報告日期，Oracle的市值為4040.4億美元，TTM年營收達673.6億美元。
