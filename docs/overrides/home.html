Under the Hood

Daily. Automated. Built from source data.

No human editors touch these reports. Every analysis runs from live market data and public filings — assembled, interpreted, and published before markets open each day.

Step 01  ·  Data Fetch

Live data assembled from market feeds and EDGAR

yfinance collects OHLCV, financials, and earnings data. SEC EDGAR scrapers pull the latest filings. Everything normalizes into a structured context package ready for the model.

yfinance + SEC EDGAR → data_fetch.py → context.py
Step 02  ·  AI Analysis

Claude reads the numbers and writes the report

The context goes to Claude Sonnet with a domain-specific prompt. The model runs full analysis, generates Mermaid charts, and produces structured markdown — no human in the loop.

prompts/*.txt + context → llm.py → claude-sonnet-4-6
Step 03  ·  Publish

GitHub Actions deploys 42 reports every morning

Cron-triggered GitHub Actions fire 42 analysis jobs per day. Reports land in the MkDocs site and publish to GitHub Pages within minutes of generation.

daily_analysis.yml → MkDocs → GitHub Pages
