Under the Hood

Daily. Automated. Built from source data.

No human editors touch these reports. Every analysis runs from live market data and public filings — assembled, interpreted, and published before markets open each day.

Step 01  ·  Data Fetch

Live data assembled from market feeds and EDGAR

yfinance collects OHLCV, financials, and earnings data. SEC EDGAR scrapers pull the latest filings. Everything normalizes into a structured context package ready for the model.

yfinance + SEC EDGAR → data_fetch.py → context.py
Step 02  ·  AI Analysis

A frontier model reads the numbers and writes the report

The context goes to the configured model — Gemini by default, with OpenAI and Claude as fallbacks — under a domain-specific prompt. The model runs the full analysis, draws Mermaid charts, and produces structured markdown; a nightly QA pass grades the output.

prompts/*.txt + context → llm.py → gemini | openai | claude
Step 03  ·  Publish

GitHub Actions publishes the whole run every morning

Cron-triggered GitHub Actions run one analysis job per ticker and report type. Reports land in the MkDocs site and publish to GitHub Pages within minutes of generation.

daily_analysis.yml → MkDocs → GitHub Pages
