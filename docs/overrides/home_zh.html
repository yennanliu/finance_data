幕後運作

每日。自動化。源於原始資料。

沒有任何人工編輯經手這些報告。每一份分析都源自即時市場資料與公開文件 — 在每天開盤前完成彙整、解讀並發布。

步驟 01  ·  資料抓取

從市場行情與 EDGAR 彙整即時資料

yfinance 蒐集 OHLCV、財務與財報資料，SEC EDGAR 爬蟲擷取最新文件。所有資料正規化為結構化的脈絡封包，供模型使用。

yfinance + SEC EDGAR → data_fetch.py → context.py
步驟 02  ·  AI 分析

前沿模型讀懂數字並撰寫報告

脈絡資料連同領域專屬的提示送入設定的模型 — 預設為 Gemini，並以 OpenAI 與 Claude 作為備援。模型執行完整分析、生成 Mermaid 圖表，並產出結構化 Markdown；每晚另有 QA 流程為產出評分。

prompts/*.txt + context → llm.py → gemini | openai | claude
步驟 03  ·  發布

GitHub Actions 每天清晨發布整輪報告

由 Cron 觸發的 GitHub Actions 為每個標的與報告類型各執行一個分析任務。報告寫入 MkDocs 網站，並在生成後數分鐘內發布至 GitHub Pages。

daily_analysis.yml → MkDocs → GitHub Pages
