步驟 02  ·  AI 分析

Claude 讀懂數字並撰寫報告

脈絡資料連同領域專屬的提示送入 Claude Sonnet。模型執行完整分析、生成 Mermaid 圖表，並產出結構化 Markdown — 全程無人介入。

prompts/*.txt + context → llm.py → claude-sonnet-4-6
