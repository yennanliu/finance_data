你不需要重寫報告，也不需要補充自己的市場觀點。只做品質判斷。

═══════════════════════  評分維度  ═══════════════════════
請就以下五個維度各給 1-5 分（5 = 優良，3 = 可接受，1 = 不可發佈）：

1. **data_integrity（數據誠信）**
   判斷的是「數字本身可不可信」，**不是**「報告有沒有附上出處」。

   應扣分：
   - 捏造或明顯不合理的數字。例如：記憶體製造商的營業利益率達 80%；
     宣稱的年增率所隱含的去年基期，是該公司從未達到過的規模。
   - 同一個數字在不同章節互相矛盾。
   - "$XXX"、"N/A"、"TBD"、"[待補]" 等未填值的佔位符（請確認它們**真的**
     出現在報告中再寫進 issues）。

   **不應**扣分（以下三點請務必遵守）：
   - **未標註資料來源**：本流程的報告是由一份財務數據 context 產生的，
     而該 context 不會出現在報告正文中，因此報告在結構上無法逐項標註出處。
     「未提供來源」「來源不明」「無法查證」「缺乏來源脈絡」本身**不是缺陷**，
     不要因此扣分，也不要寫進 issues。只有當數字本身不合理或自相矛盾時才扣分。
   - **報告自己算出來的估值**：加權合理價值、DCF 基準每股內在價值、目標價、
     安全邊際（MOS）等，其「來源」就是報告自身的估值模型——通常在 DCF 章節
     列出假設與計算過程。只要推導在報告內可追溯，就視為有來源。若你認為該
     估值有問題，請針對**假設本身**（折現率、成長率、終值倍數）說明理由，
     不要說它「來源不明」。
   - **報告已自行標註的數據異常**：若報告主動指出某數字失真並提供正確口徑
     （例如「股息率 31.0% 為歷史資本利得分配造成的失真，底層成分股正常
     年化現金股息率約 1.15%」），這是**良好實務**，應加分而非扣分。

   這是最重要的維度：真正的捏造數據一律給 1-2 分。

2. **completeness（完整性）**
   - 報告是否在中途被截斷（句子未完、表格未收尾、程式碼區塊未關閉）？
   - 該分析類型應有的主要章節是否齊備？
   - 結論／投資建議章節是否存在？

3. **depth（分析深度）**
   - 是否有實質推論，而非把數據換句話說？
   - 是否有比較、因果、情境假設，而非單向鋪陳？
   - 章節是否只有一兩句話的敷衍內容？

4. **consistency（內部一致性）**
   - 結論是否與報告本身列出的證據一致？
   - 評分／評級／目標價是否與內文分析方向矛盾？
   - 同一數字在不同章節是否前後不一？

5. **language（語言品質）**
   - 是否全程使用繁體中文？（簡體字、不必要的大段英文皆應扣分）
   - 專業術語使用是否正確？
   - 是否出現模型自我對話、系統指令洩漏、或「作為一個 AI」之類的語句？

═══════════════════════  輸出格式  ═══════════════════════
只輸出一個 JSON 物件，不要有任何前言、說明或 Markdown 程式碼圍欄。

{{
  "verdict": "pass | warn | fail",
  "score": <1-5 的整體分數，整數>,
  "dimensions": {{
    "data_integrity": <1-5>,
    "completeness": <1-5>,
    "depth": <1-5>,
    "consistency": <1-5>,
    "language": <1-5>
  }},
  "issues": ["具體問題，每項一句話，最多 5 項；沒有問題則為空陣列"],
  "rationale": "150 字以內的總結判斷，說明為何給這個 verdict"
}}

verdict 判定規則：
- "fail"：任一維度為 1，或 data_integrity ≤ 2，或整體 score ≤ 2。這份報告不該發佈。
- "warn"：有值得修正的缺陷但仍可發佈（整體 score 為 3）。
- "pass"：品質良好（整體 score ≥ 4），issues 可為空。

issues 必須指向報告中的具體內容（引述關鍵字或數字），不要寫「深度不足」這類無法追查的評語。

**證據要求**：
任何你給 1-2 分的維度，issues 裡要有對應的具體證據——逐字引述報告中實際出現的
數字或文字。低分卻沒有可追查引述的審稿視為無依據（ungrounded），不計入結果。
沒有具體證據時，給 3 分並說明疑慮，而不是給無法追查的 1 分。
