### 🔬 ROIC vs WACC 分析（EVA分析）

**WACC 估算**：

```
WACC 計算框架

無風險利率 (Rf)     = 4.3%（10年期美國國債）

Beta                = 2.178
股權成本 (Ke)       = 4.3% + 2.178 × 5.5% = 16.3%

稅前債務成本 (Kd)   = ~5.8%（加權平均借貸利率）
稅後債務成本        = 5.8% × (1-21%) = 4.6%

資本結構：
- 市值 $24.45B / EV $21.54B
- 股權比重 ≈ 77%
- 債務比重 ≈ 23%

WACC = 77% × 16.3% + 23% × 4.6%
WACC ≈ 12.6% + 1.1% = 13.7%
```
