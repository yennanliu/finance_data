### 🔬 DuPont 三因子分解（FY2025）

```
ROE = 淨利率 × 資產週轉率 × 財務槓桿

淨利率     = -50.4%  （淨虧損/收入）
資產週轉率 = 0.386x  （$244.4M ÷ $633.8M）
財務槓桿   = 1.436x  （$633.8M ÷ $441.3M）

ROE = (-50.4%) × 0.386 × 1.436 = -27.9% ✓

問題核心：淨利率嚴重為負 → 提升淨利率是改善ROE的唯一關鍵
資產週轉率偏低 → 需要更有效利用衛星資產
財務槓桿溫和 → 財務結構相對保守，不是問題所在
```
