## 🏢 公司概覽

台灣積體電路製造股份有限公司（TSMC，NYSE：TSM）是全球最大的專業積體電路製造服務（晶圓代工）企業，總部位於台灣新竹科學園區。公司成立於1987年，目前市值位居全球前十大企業之列。TSMC 掌握全球最先進的半導體製程技術，包括3奈米、2奈米及即將量產的1.6奈米（A16）製程，是 Apple、NVIDIA、AMD、Qualcomm、Intel 等全球頂尖科技公司的核心晶圓代工夥伴。
