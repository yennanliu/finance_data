## 🏢 公司概覽

**Palantir Technologies Inc.（PLTR）** 是一家總部位於美國科羅拉多州丹佛市的資料分析與人工智慧軟體公司，由 Peter Thiel、Alex Karp 等人於 2003 年創立。公司主要業務分為兩大板塊：
